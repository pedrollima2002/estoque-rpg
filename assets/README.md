# Identidade visual

Coloque os arquivos oficiais da RPG Multimarcas nesta pasta com estes nomes:

- `logo-rpg.png`: logo usada no login e na barra lateral.
- `favicon.png`: ícone exibido na aba do navegador.
- `app-icon.png`: ícone quadrado para atalhos no celular.

A logo não foi inventada nem substituída por uma imagem provisória. Enquanto o arquivo oficial não existir, o sistema usa o nome textual da loja.
